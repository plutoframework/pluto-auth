# Security policy

Pluto Auth is pre-release and has not had an independent security audit.
Only the current main revision is maintained at this stage.

Do not post credentials, exploit details or sensitive data in public issues.
Use this repository's GitHub private vulnerability reporting facility:
https://github.com/plutoframework/pluto-auth/security/advisories/new

Include the affected commit, configuration, reproducible steps and impact.
There is currently no guaranteed response-time commitment. Maintainers triage
reports, add regression tests, coordinate disclosure and publish fixes/advisories.
Do not send Pluto reports to Limen's maintainer; this fork is independent.

See docs/SECURITY-MODEL.md for the implemented boundaries and known limitations.
